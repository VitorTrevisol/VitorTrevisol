### ⚡ O que venho construindo & Especialidades

- 🏛️ **Modern Data Lakehouse**: Desenho e implementação de arquitetura medalhão (**Bronze** ➔ **Silver** ➔ **Gold**) para ingestão em larga escala e democratização de dados analíticos.
- ☁️ **Cloud Data Platform (GCP)**: Criação de pipelines com **Google BigQuery**, **Cloud Storage (GCS)**, particionamento e clustering para redução de custos e alta performance em SQL analítico.
- 🔄 **Orquestração & Integração de APIs**: DAGs automatizadas no **Apache Airflow**, extração e sync de APIs complexas (VTEX, ERPs, Webhooks) e desenvolvimento de microsserviços com **FastAPI**.
- 🤖 **Inteligência Artificial & Agentes**: Desenvolvimento de agentes de automação integrados via **Model Context Protocol (MCP)** e integração de LLMs a fluxos de dados corporativos.
- 📊 **BI & Data Analytics**: Modelagem dimensional e dashboards interativos no **Looker Studio** para tomada de decisão no varejo e e-commerce.
